# Sysadmin Homelab

A documented enterprise IT homelab built from scratch using VMware Workstation Pro. This lab  demonstrates hands-on experience with Windows Server, Active Directory, Group Policy, Linux administration, and network configuration.

## Lab Environment

| Component | Details |
|-----------|---------|
| Hypervisor | VMware Workstation Pro |
| Domain Controller | Windows Server 2019 (DC01) |
| Client Machine | Windows 10 (CLIENT01) |
| Linux Server | Ubuntu 24.04 LTS (TesterLab) |
| Network Simulator | Cisco Packet Tracer |
| Domain | homelab.local |
| Network | 192.168.80.0/24 |

## Skills Demonstrated

- VMware Workstation Pro virtual machine deployment and configuration
- Windows Server 2019 installation and administration
- Active Directory Domain Services installation and promotion
- Organizational Unit creation and user account management
- Group Policy Object creation, configuration, and deployment
- Windows 10 domain join and domain user authentication
- Linux command line administration (Ubuntu 24.04)
- Static IP configuration across Windows and Linux systems
- Network troubleshooting using ping, ipconfig, ip addr
- Cisco Packet Tracer network simulation and routing configuration
- VMware virtual network configuration (VMnet/Host-only)

## Purpose

This homelab was built to develop and demonstrate hands-on IT skills for roles in system administration, desktop support, cybersecurity, and network operations. Each phase is documented with screenshots showing real configuration and output.
